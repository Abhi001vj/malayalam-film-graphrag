OPTIONAL DEVICE EXPERIMENT

A small model. A fixed query plan.

Try turning a movie question into a permitted intent and named entities entirely in this browser. The model produces JSON, which is independently validated by the server before use. It never creates SQL or a factual movie answer.

Loading downloads model files from MLC/Hugging Face/CDN hosts. The 360M quantized model configuration estimates about 376 MB of GPU memory; total browser memory and download size differ. Performance, name spelling and Malayalam accuracy need evaluation on your device. The regular app works without this model.

Checking browser support…

No model is downloaded automatically.

This is an experiment, not an accuracy claim. Review the extracted entities. Use the normal search if the plan is incomplete. Cached model files may remain in browser storage after GPU unloading; use the browser’s site-data controls to remove them.
